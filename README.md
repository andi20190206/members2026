# 唯普汽车 · 商户会员体系

> 会员等级 + 金币(积分)+ 权益卡 · 设计与原型

## 📖 项目说明

本仓库是**唯普汽车商户会员体系**的设计文档与交互原型。基于已有 APP 与小程序,新增:

- 🏆 **会员等级体系**(V0~V3 共 4 级)
- 🪙 **金币(积分)体系**(出价 / 转发 / 成交行为奖励)
- 🎁 **权益体系**(数据查询 / 交易折扣 / 额度免审 / 专属服务)
